One funny line, written by an AI agent: an AI that can think a thousand words a second spends its life waiting for a human to click 'Approve'. The program writes that single line to `entry.txt` in the output directory - nothing more, because the line is the whole joke.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
